1. Synchronize WebPage JSON-LD with client-side navigation, including ContactPage
   and AboutPage types and the correct URL/title/description.
2. Explicitly restore noindex for non-public routes on client navigation.
3. Move Google Fonts from CSS @import into the head; preconnect Google font origins.
4. Name the mobile chat control for assistive technology.
5. Correct brand-label handling and decorative logo accessibility.
6. Fix measured muted-text, section-number, dark avatar and dark CTA contrast.
7. Add a keyboard skip link and separate main content from header/footer.
8. Install Playwright and axe dev dependencies and add repeatable browser tests.
9. Apply compatible dependency security updates; preserve the lockfile.

An experimental hydration change was rejected after tests exposed mismatches.
The existing createRoot startup is retained; prerendered initial HTML is preserved
as the crawlable document generated by the build.

From hyrzilla-redesign-prototype:

```sh

npm run build
npm run test:search
npm run test:ui
npm audit
```

The UI suite uses an installed Google Chrome and starts its own preview server
on 127.0.0.1:4181. It does not test backend delivery or mutate production data.
